# claude-code-template

Starter template for Claude Code projects.

## Setup

1. Clone this repo into your new project folder
2. In `CLAUDE.md`, replace `[SPEC_FILE]` with the name of your spec/build plan file
3. In `PROGRESS.md`, replace `[Project Name]`, `[DATE]`, and `[SPEC_FILE]`
4. Delete this setup section when done

## Files

- `CLAUDE.md` -- Claude Code behavior standards (session health, model routing, constraints)
- `PROGRESS.md` -- living progress tracker; update after each session
